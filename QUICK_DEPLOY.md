# 🚀 Quick Deploy to GitHub (5 Minutes)

## You Need:
1. A GitHub account (create free at github.com)
2. 5 minutes

---

## Steps:

### 1. Create Repository on GitHub

1. Go to https://github.com/new
2. Name: `Project-CleanLoom`
3. Description: `Lint reduction solution for weaving workshops`
4. Choose: **Public** (for free website)
5. ❌ Don't add README, .gitignore, or license
6. Click "Create repository"

---

### 2. Push Your Project

**Copy these commands and run them** (replace `YOUR-USERNAME`):

```bash
cd /Users/rhuria/Project_CleanLoom

git remote add origin https://github.com/YOUR-USERNAME/Project-CleanLoom.git

git push -u origin main
```

**Done!** Your project is now on GitHub 🎉

---

### 3. Enable the Website

1. Go to your repo on GitHub
2. Click **Settings** (top menu)
3. Click **Pages** (left sidebar)
4. Under "Branch": Select **main** and **/ (root)**
5. Click **Save**

**Wait 2 minutes.** Your website will be live at:

```
https://YOUR-USERNAME.github.io/Project-CleanLoom/
```

## Adding Team Members:

1. Repository → **Settings** → **Collaborators**
2. Click **"Add people"**
3. Enter their GitHub username/email
4. They get an invite email

**Now they can edit files directly on GitHub!**

---

## When They Edit:

1. They go to the file on GitHub
2. Click the pencil icon ✏️
3. Make changes
4. Click "Commit changes" at bottom
5. Website updates automatically in 1-2 minutes

**That's it!** No Git knowledge needed for basic editing.
