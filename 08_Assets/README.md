# Assets Folder

This folder contains all media assets, photos, diagrams, and other visual materials for the CleanLoom project.

---

## Folder Structure

```
08_Assets/
├── Photos/
│   ├── Workshop_Photos/          # Workshop documentation photos
│   ├── Prototype_Photos/          # Prototype build and testing photos
│   ├── Before_After/              # Comparison photos showing impact
│   └── Team_Photos/               # Team and stakeholder photos
├── Diagrams/
│   ├── Technical_Drawings/        # CAD files, technical specifications
│   ├── Infographics/              # Visual explanations and charts
│   └── Flow_Diagrams/             # Process flows, system diagrams
├── Videos/
│   ├── Workshop_Videos/           # Workshop operations, interviews
│   ├── Prototype_Demos/           # Prototype demonstrations
│   └── Training_Videos/           # User training materials
├── Presentations/
│   └── Pitch_Decks/               # Presentations for stakeholders
└── Brand_Assets/
    └── Logos/                     # Project logos and branding
```

## File Naming Conventions

### Photos
Format: `YYYYMMDD_Location_Subject_###.jpg`

Examples:
- `20251203_Workshop_A_LoomCloseup_001.jpg`
- `20251210_Prototype_FilterAssembly_003.jpg`

### Videos
Format: `YYYYMMDD_Location_Subject.mp4`

Examples:
- `20251203_Workshop_A_Interview.mp4`
- `20251220_Lab_PrototypeTest.mp4`

### Diagrams
Format: `Type_Description_v##.extension`

Examples:
- `Technical_SystemDiagram_v01.pdf`
- `Infographic_LintImpact_v02.png`

---

## Image Requirements

### For Documentation
- **Format**: JPG or PNG
- **Resolution**: Minimum 1920x1080
- **Size**: Optimize for web (< 2MB per image)

### For Printing
- **Format**: PNG or PDF
- **Resolution**: 300 DPI minimum
- **Color mode**: CMYK for print, RGB for digital

### For Presentations
- **Format**: PNG (for transparency) or JPG
- **Resolution**: 1920x1080 or 16:9 aspect ratio
- **Size**: Optimize for quick loading

---

## Video Requirements

- **Format**: MP4 (H.264 codec)
- **Resolution**: 1920x1080 (1080p) preferred
- **Frame rate**: 30fps
- **Audio**: 44.1kHz, stereo
- **Length**: Keep workshop videos under 5 minutes when possible

---

## Usage Rights & Privacy

### Workshop Photos
- Always get verbal/written consent before photographing people
- Blur faces if privacy is requested
- Do not share identifiable photos without permission

### Prototype Photos
- Open for project use
- Can be shared publicly unless proprietary design

### Attribution
When using assets in publications:
- Credit: "CleanLoom Project, [Year]"
- Include project website if available

## Asset Management

### Check-in Process
1. Capture asset with proper naming
2. Review for quality and clarity
3. Add to appropriate folder
4. Update asset log (see below)
5. Backup to cloud storage

### Asset Log

Maintain a spreadsheet with:
- File name
- Date captured
- Location/subject
- Purpose
- Usage rights
- Notes

---

## Quick Start

### Adding New Photos
1. Transfer from camera/phone to computer
2. Rename using naming convention
3. Organize into appropriate subfolder
4. Add entry to asset log
5. Backup to cloud

### Creating Diagrams
1. Use preferred tool (CAD, Illustrator, PowerPoint, etc.)
2. Save working file (.ai, .dwg, .pptx) and export (PDF/PNG)
3. Version number in filename
4. Store both working file and export

### Processing Videos
1. Edit using preferred software
2. Export as MP4 (H.264)
3. Add captions/subtitles if needed
4. Store both raw footage and final edit
